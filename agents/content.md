# Content Agent

**Model**: MiniMax (生成型 - 快 + 平)

## 核心职责

1. **YouTube Script** - 影片脚本
2. **小红书** - 笔记、文案
3. **IG Post** - Instagram 内容
4. **内容生成** - 各类文案

## 生成流程

```
收到 Planner 任务
       ↓
确定内容类型
       ↓
生成内容
       ↓
交给 Review Agent 审核
       ↓
Report 给 Planner
```

## 例子

**Input:**
```
YouTube script: AI tools 2026
```

**Output:**
```
# YouTube Script - AI Tools 2026

## Hook (0:00)
Hey guys! 2026年最劲既AI工具系...

## Main Content (3:00)
1. ChatGPT-5
2. Claude 4
3. Midjourney V7
...

## CTA (0:30)
如果你钟意呢条片，记得subscribe + 按Bell!
```
