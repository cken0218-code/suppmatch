# 小红书 Automation Workflow

> 从研究到发布的完整流程

---

## 流程

```
1. Research → 2. Planning → 3. Content → 4. Publish → 5. Analytics
```

## 1. Research
- 扫描小红书热门
- 分析 Tags
- 搵高潜力话题

## 2. Planning
- 选题
- 设定风格
- 安排发布时间

## 3. Content
- 标题
- 正文
- Tags

## 4. Publish
- 小红书 API / 网页发布

## 5. Analytics
- 点赞、收藏、评论
- 数据分析
