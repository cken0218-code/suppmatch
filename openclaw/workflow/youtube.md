# YouTube Automation Workflow

> 从研究到发布的完整流程

---

## 流程

```
1. Research → 2. Planning → 3. Script → 4. Generate → 5. Upload → 6. Analytics
```

## 1. Research
- 扫描 YouTube Trending
- 分析竞争对手
- 搵热门 niche

## 2. Planning
- 选题
- 制定标题
- 安排发布时间

## 3. Script
- Hook (前10秒)
- Main Content (3-5分钟)
- CTA + End Screen

## 4. Generate
- AI 影片 (Runway/Pika)
- AI 图片 (Midjourney)
- 剪辑

## 5. Upload
- YouTube API 上传
- 设置标题、描述、标签

## 6. Analytics
- 观看数、点赞、评论
- 数据分析
- 优化建议
