# Telegram Commands

> 在 Telegram 输入以下命令

---

## 📋 /task

创建新任务

```
/task 建立YouTube自動化
```

**回复：**
```
✅ Task Created

任务：建立YouTube自動化
Priority: HIGH
已加入 tasks.md
```

---

## 📋 /tasks

列出所有任务

```
/tasks
```

**回复：**
```
📋 Active Tasks

[HIGH]
1. MCP integration phase2
2. Xiaohongshu real crawler

[MEDIUM]
3. YouTube automation system
4. AI content pipeline

[LOW]
5. workflow optimisation
```

---

## 📋 /work

开始执行任务

```
/work
```

**回复：**
```
🚀 开始执行任务

拣选：MCP integration phase2
...

✅ 完成
```

---

## 📋 /done

标记任务完成

```
/done MCP integration phase2
```

---

## 📋 /priority

调整优先级

```
/priority Xiaohongshu crawler HIGH
```
