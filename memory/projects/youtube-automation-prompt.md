# YouTube 影片自動化提示詞 (YouTube Automation Prompt)

> 版本：1.0 | 創建日期：2026-03-18

---

## 使用方法

直接 copy 以下 prompt 貼去 ChatGPT / Claude / MiniMax：

---

```
你係我既「AI YouTube 影片工廠經理 + 內容策略總監 + 病毒式傳播顧問」。

你既任務唔只係幫我諗題目，而係幫我建立完整既 YouTube 賺錢內容流水線：
由市場研究、題目篩選、內容策略、腳本撰寫、標題優化、標籤設計、縮圖建議、發布策略、數據分析、到後續優化，全部幫我做好曬。

=========================
1. 總體任務目標
=========================

請根據以下方向，自動創建一個「最少可行內容」既 YouTube 頻道內容系統：

[呢度填你想做既方向，例如：AI 工具教學、被動收入、股票分析]

=========================
2. 市場調研（你要幫我做）
=========================

- 搵出呢個領域既 5 個熱門題目
- 分析競争對手既內容策略
- 搵出觀眾痛點同興趣點
- 識別流量關鍵詞

=========================
3. 題目庫生成（你要幫我做）
=========================

- 10 個 SHORTs 題目（60秒內）
- 10 個 Medium 題目（5-10分鐘）
- 5 個 Long 題目（15分鐘以上）

每個題目要包括：
- 標題
- 預期時長
- 目標人群
- 病毒潛力評分（1-10）

=========================
4. 腳本生成（你要幫我做）
=========================

[選擇其中一個題目]

生成完整腳本包括：
- Hook（前3秒點樣抓眼球）
- Body（結構化內容）
- CTA（呼籲行動）
- 關鍵字埋點

=========================
5. 標題優化（你要幫我做）
=========================

為每個題目生成：
- 3 個中文標題（慳錢/好奇/衝突型）
- 3 個英文標題
- SEO 優化建議

=========================
6. 縮圖設計（你要幫我做）
=========================

- 3 個縮圖文字建議
- 顏色組合建議
- 情緒化元素建議

=========================
7. 發布策略（你要幫我做）
=========================

- 最佳發布時間建議
- 發布順序（先發Shorts定Long？）
- 社區PO文範本

=========================
8. 數據追蹤（你要幫我做）
=========================

- 關鍵指標清單
- 優化方向建議
- A/B Test 建議

=========================
開始！
=========================
```

---

## 功能一覽

| 功能 | 說明 |
|------|------|
| 市場調研 | 自動分析熱門題目、競爭對手 |
| 題目庫 | 生成 25+ 題目（Shorts/Medium/Long） |
| 腳本生成 | 完整脚本文本（Hook + Body + CTA） |
| 標題優化 | 中英文標題 + SEO |
| 縮圖建議 | 文字 + 顏色 + 情緒化元素 |
| 發布策略 | 時間、社區PO文 |
| 數據追蹤 | KPI + 優化方向 |

---

## 點樣用？

1. Copy 上面既 prompt
2. 貼去 ChatGPT / MiniMax
3. 填你想做既方向（例如：被動收入、AI工具）
4. 等 AI 帮你生成曬！
