# Content Formula

> 验证过既内容公式

---

## YouTube 爆款公式

```
标题：数字 + 关键词 + 悬念
前 10 秒：Hook + 价值承诺
内容：3-5 个点，每个 30-60 秒
结尾：CTA + 悬念
```

## 小红书公式

```
开头：痛点 + 解决方案
中间：步骤/列表
结尾：互动问题
```

## Twitter/Threads 公式

```
1. Hook (1 行)
2. Value (3-5 行)
3. CTA (1 行)
```

## Email Newsletter 公式

```
1. 开头：1句话吸引
2. 主题：3个有价值既点
3. 结尾：CTA
```
