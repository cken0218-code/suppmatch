## 🎯 TikTok Shop 是什麼？

### 定義

TikTok Shop 是一個內置電子商務功能，讓用戶在不離開 TikTok 應用程序的情況下瀏覽和購買產品。2026 年，該平台成為社交商務增長的中心，融合了創作者驅動的內容與一鍵購買。

### 發現式商務 vs 傳統電商

| 類型 | 模式 | 例子 | TikTok Shop 優勢 |
|------|------|------|-----------------|
| **發現式商務** | 產品通過娛樂視頻和算法推薦出現在用戶的 Feed 中 | TikTok Shop | ✅ 達到未主動購物的人 |
| **搜索式商務** | 客戶輸入特定查詢來查找他們已決定購買的物品 | Amazon | ❌ 需要主動搜索 |

### 為何重要？

- **快速增長**: TikTok Shop 已成為美國增長最快的電子商務渠道之一
- **算法優勢**: 內容找客戶，不是客戶找內容
- **完整生態**: 娛樂應用 → 完整購物生態系統
- **先發優勢**: 早期品牌正在觀察競爭對手爭相追趕

class TikTokShopTracker:
    def __init__(self):
        self.products = {}
    
    def add_product(self, product_id, name, commission_rate):
        self.products[product_id] = {
            'name': name,
            'commission': commission_rate,
            'clicks': 0,
            'sales': 0,
            'revenue': 0
        }
    
    def track_click(self, product_id):
        self.products[product_id]['clicks'] += 1
    
    def track_sale(self, product_id, amount):
        self.products[product_id]['sales'] += 1
        self.products[product_id]['revenue'] += amount * self.products[product_id]['commission']
    
    def get_best_performer(self):
        return max(self.products.items(), key=lambda x: x[1]['revenue'])
