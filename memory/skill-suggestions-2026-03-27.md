## 🏆 本周推荐 Skills（3月14-20日）

### 1️⃣ nano-banana-pro - 文字生成图像（推荐）
**名称**: nano-banana-pro
**用途**: 文字生成图像工具（Text-to-Image）
**描述**: 基于 Google Gemini 3 Pro Image 模型，**特性**:
- 支持 1K, 2K, 4K 分辨率
- AI agent 可生成高质量图像
**建议安装原因**: 与用户 YouTube automation 相关（缩略图生成）
**安全评级**: ✅ 安全（来自官方推荐）

### 2️⃣ weather - 天气集成
**名称**: weather
**用途**: 通过 wttr.in 获取即时天气预报
**描述**: 无需 API key，全球任何地点的天气预报
**特性**:
- 即时天气
- 旅行规划
- 户外活动准备
- 检查是否需要带伞
**建议安装原因**: 已安装 ✅（TOOLS.md 确认）
**安全评级**: ✅ 安全（无需 API key）

### 3️⃣ github - GitHub 自动化助手
**名称**: github
**用途**: 将 OpenClaw 变成编码副驾驶
**描述**: 自动化 GitHub 工作流
**特性**:
- 列出 issues
- 创建 branches
- 编写 fixes
- 打开 PRs
- 响应 review comments
**建议安装原因**: 与用户开发工作流高度相关
**安全评级**: ✅ 安全（已安装，TOOLS.md 确认）
